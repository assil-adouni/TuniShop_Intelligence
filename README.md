# 🛍️ TuniShop Intelligence

### Business Intelligence | Analyse commerciale | Machine Learning

## 📌 Présentation

**TuniShop Intelligence** est une application décisionnelle dédiée à l'analyse des performances commerciales d'une activité e-commerce.

Le projet exploite les données de vente afin de suivre les indicateurs clés de performance, analyser la rentabilité et accompagner la prise de décision grâce à des techniques de Business Intelligence et de Machine Learning.

## 🎯 Objectifs

- Analyser le chiffre d'affaires et la marge brute.
- Évaluer les performances par région et catégorie.
- Identifier les tendances commerciales.
- Détecter les transactions atypiques.
- Exploiter des modèles de Machine Learning.
- Proposer des recommandations commerciales.

## ⚙️ Fonctionnalités

- **Dashboard interactif :** visualisation des KPI et graphiques.
- **Analyse commerciale :** comparaison des régions et catégories.
- **Détection d'anomalies :** identification des observations inhabituelles avec Isolation Forest.
- **Prédiction :** estimation du chiffre d'affaires avec des modèles de régression.
- **Recommandations :** aide à l'identification des catégories nécessitant une attention commerciale.
- **Exportation :** téléchargement des données filtrées.

## 🚀 Exécution locale

1. Cloner le dépôt :

```bash
git clone https://github.com/assil-adouni/TuniShop_Intelligence.git
```

2. Accéder au dossier :

```bash
cd TuniShop_Intelligence
```

3. Créer un environnement virtuel :

```bash
python -m venv .venv
```

4. Activer l'environnement sous Windows :

```powershell
.venv\Scripts\activate
```

5. Installer les dépendances :

```bash
pip install -r requirements.txt
```

6. Lancer l'application :

```bash
streamlit run app.py
```
